🚀 Portfólio — Cisco Packet Tracer
📌 Sobre o Projeto

Este portfólio apresenta projetos desenvolvidos utilizando o Cisco Packet Tracer, uma ferramenta amplamente utilizada para simulação e configuração de redes de computadores.

O objetivo deste repositório é demonstrar conhecimentos em:

Configuração de redes
Endereçamento IP
VLANs
Roteamento
DHCP e DNS
Segurança de rede
Troubleshooting
Simulação de ambientes corporativos
🖥️ Tecnologias Utilizadas
Cisco Systems Packet Tracer
Redes Cisco
IPv4 / IPv6
Switching & Routing
Protocolos de Rede
